
# SAP S/4HANA – Order-to-Cash (O2C) Process

## 1. Objective
To understand the end-to-end Order-to-Cash process in SAP S/4HANA Sales and Distribution.

## 2. O2C Business Process Flow

1. Customer Inquiry
2. Quotation
3. Sales Order
4. Outbound Delivery
5. Picking
6. Post Goods Issue (PGI)
7. Billing
8. Accounting Document

## 3. Important Transaction Codes

| T-Code | Purpose |
|---|---|
| VA11 | Create Inquiry |
| VA21 | Create Quotation |
| VA01 | Create Sales Order |
| VA03 | Display Sales Order |
| VL01N | Create Outbound Delivery |
| VL02N | Change Outbound Delivery |
| VL03N | Display Outbound Delivery |
| VF01 | Create Billing Document |
| VF03 | Display Billing Document |

## 4. Key Process Activities

### Sales Order
- Create a sales order.
- Verify customer and material details.
- Check pricing determination.
- Review schedule lines.

### Delivery
- Create outbound delivery.
- Perform picking where applicable.
- Verify delivery quantities.

### Post Goods Issue
- Execute PGI.
- Understand inventory and goods movement impact.

### Billing
- Create billing documents.
- Verify billing values.
- Understand accounting integration.

## 5. Document Flow

Document the relationship between sales orders, deliveries, goods issue and billing documents.

## 6. Practical Learning

Document the O2C activities practised in the SAP S/4HANA practice environment, including sales order creation, PGI and billing.

## 7. Key Learning Outcomes

- Understood the end-to-end O2C process.
- Practised sales order processing.
- Executed PGI and billing.
- Understood document flow and integration concepts.
